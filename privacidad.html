Qué datos se usan

asistente-lab accede a la cuenta de Gmail de su propietario mediante la API de Gmail, con su autorización expresa (OAuth). Usa el remitente, el asunto, el cuerpo y las cabeceras de autenticación de los mensajes que llevan la clave acordada, y envía respuestas desde esa misma cuenta.

Cómo se usan

Los mensajes se procesan solo para ejecutar la tarea solicitada y responder. El procesamiento ocurre en un computador local del propietario; los modelos de lenguaje que interpretan las tareas también se ejecutan localmente. No se envían datos de Gmail a otros servicios.

Con quién se comparten

Con nadie. Los datos no se venden, no se comparten con terceros, no se usan para publicidad ni para entrenar modelos de inteligencia artificial generales.

Uso limitado

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Conservación y eliminación

Los resultados de las tareas se guardan en el computador local del propietario. El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions.
